# Architecture Decision Records

One decision per file: `adr-NNN-<slug>.md` (three-digit, zero-padded).
Template: `.claude/docs/templates/architecture-decision-record.md`.
Created and revised with `/architecture-decision`.

## Required ADRs

Populated by `/create-architecture`. Build does not start on a decision whose
ADR is still `Proposed`.

| ADR | Title | Why it matters | Status |
|-----|-------|----------------|--------|
| ADR-001 | _example: Authentication & session model_ | Security boundary, hard to change later | needed |
| ADR-002 | _example: Multi-tenancy approach_ | Data isolation, pervasive | needed |
| ADR-003 | _example: Sync vs async job boundary_ | Shapes the runtime | needed |
