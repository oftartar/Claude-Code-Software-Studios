# docs/specs/

One file per feature: `<feature-slug>.md`. Written by `/write-spec`, reviewed
across the set by `/review-specs`.

Structure enforced by `.claude/rules/design-docs.md`:
Problem → Goals → Non-Goals → Users & Scenarios → Requirements (numbered) →
UX Notes → Data & API Impact → Acceptance Criteria → Open Questions → Rollout.

Template: `.claude/docs/templates/feature-spec.md`.
