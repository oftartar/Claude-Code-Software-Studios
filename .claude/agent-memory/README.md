# agent-memory/

Per-agent persistent notes for agents whose definition sets `memory: project`.
Each such agent gets a subfolder with a `MEMORY.md` it maintains across sessions
(durable decisions, gotchas, conventions it has learned for this project).

```
agent-memory/
  lead-engineer/MEMORY.md
  technical-director/MEMORY.md
  ...
```

Keep entries short and factual. This is not a log — stale or wrong notes should
be deleted.
